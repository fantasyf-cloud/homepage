Supabase 설정 — 방명록 + 방문자 카운터 (5분이면 됩니다)
============================================================

[1] Supabase 프로젝트 만들기
- supabase.com 가입 → New project → 무료 플랜 (1~2분 소요)

[2] 아래 SQL을 SQL Editor에서 실행 (방명록 테이블 + 방문 기록 테이블)
------------------------------------------------------------------------
create table guestbook (
  id bigint generated always as identity primary key,
  name text not null,
  message text not null,
  created_at timestamptz default now()
);
alter table guestbook enable row level security;
create policy "public read" on guestbook
  for select using (true);
create policy "public insert" on guestbook
  for insert with check (true);

create table visits (
  id bigint generated always as identity primary key,
  created_at timestamptz default now()
);
alter table visits enable row level security;
create policy "public read" on visits
  for select using (true);
create policy "public insert" on visits
  for insert with check (true);
------------------------------------------------------------------------
* RLS 정책 덕분에 읽기/쓰기만 허용되고 다른 작업은 안 됩니다.

[3] 키 복사 후 HTML에 입력
- Project Settings → API에서 URL과 anon public key 복사
- guestbook.html의 두 줄과 index.html의 두 줄에 같은 값 입력:
    SUPABASE_URL / SUPABASE_ANON_KEY
- anon key는 프론트엔드에 공개되도록 설계된 키라 HTML에 넣어도 됩니다.

[4] 배포
- repo 폴더에 파일 넣기 → 배포.bat 더블클릭 → 끝

참고:
- 카운터는 '방문 횟수' 기준입니다 (같은 사람이 새로고침하면 올라감).
  정확한 순방문자 수가 필요하면 나중에 IP 기준 중복 제거로 바꿀 수 있음.
- Supabase 설정 전에는 카운터가 화면에 안 보입니다 (자동 숨김).
